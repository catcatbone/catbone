# 今天吃什么转盘

- 日期：2026-07-28
- 用户需求：做一个可以本地打开的网站，用转盘选择今天吃什么，并记录历史记录。
- 主要成果：React + Vite 本地美食决定器，包含转盘、菜品编辑、历史记录、本地持久化和响应式布局。
- 文件清单：
  - `package.json`：启动与构建脚本
  - `index.html`：页面入口
  - `src/main.jsx`：转盘、直接编辑菜品、历史记录交互逻辑和日期规则
  - `src/styles.css`：完整视觉与响应式样式
  - `dist/`：已构建的生产文件
- 备注：数据只保存在当前浏览器的 `localStorage` 中，不会上传到网络。

## 启动

在本目录打开终端：

```bash
npm install
npm run dev
```

然后访问终端显示的本地地址（通常是 `http://127.0.0.1:5173/`）。

## 功能

- 点击“开始转盘”或按空格键随机选择菜品。
- 选择完成后自动写入历史记录。
- “编辑菜品”可以新增和删除选项。
- 编辑状态下可直接在菜品列表中输入修改名称。
- 每条历史记录右侧都有独立删除按钮。
- 历史区支持手动录入菜品、日期和备注。
- 转盘每天自动排除昨天历史中出现过的菜品；如果昨天吃过全部选项，会提示先添加新菜品。
- 默认桌面窗口已优化为一屏布局，转盘文字和色块可读性加大；手机端仍按内容自然滚动。
- “重置转盘”回到初始角度；“清空历史记录”清理历史。
